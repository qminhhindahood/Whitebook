# Use an independent visual identity

Whitebook may closely reproduce generic digital-exam structure and interaction patterns, including timed Modules, a split question-and-answer layout, review navigation, calculator and reference overlays, loading gates, and result states. Its implementation, assets, icons, wording, color system, and visual details will be independently created rather than copied from Bluebook or Bluebooky; Whitebook remains a private working name and must be reconsidered before public distribution because of its similarity to Bluebook.
