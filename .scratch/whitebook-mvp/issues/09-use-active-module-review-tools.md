# 09 — Use active-Module review tools

**What to build:** Familiar active-Module tools that help the learner navigate and review without changing the grading contract or allowing access outside the current Module.

**Blocked by:** 06 — Pause, recover, and resume Attempts.

**Status:** ready-for-agent

- [ ] The Question Menu is limited to the active Module and distinguishes current, answered, unanswered, and marked questions.
- [ ] Mark for Review persists across navigation, pause, resume, and restart.
- [ ] The learner can eliminate and restore answer choices without changing the selected response or grading outcome.
- [ ] The Question Region viewer supports zoom and pan while maintaining accurate content framing.
- [ ] The divider between Question Regions and native answer controls is resizable and remains usable at the supported laptop viewport.
- [ ] The timer can be hidden and restored without affecting timing.
- [ ] A silent visual warning appears once at five minutes, stays until dismissed, and does not stop the timer.
- [ ] Ordinary native browser focus and answer-control behavior remain intact without adding a custom shortcut system.
- [ ] Browser tests verify every visible review state and persistence behavior without asserting React implementation details.
