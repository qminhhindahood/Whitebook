# 11 — Review Results and practise mistakes

**What to build:** A Results experience that explains performance through honest Raw Accuracy and timing, supports focused question review, and turns missed questions from one source into a new Practice plan.

**Blocked by:** 07 — Configure Practice with the Practice Builder; 09 — Use active-Module review tools.

**Status:** ready-for-agent

- [ ] Results show correct, incorrect, unanswered, percentage, and overall elapsed time.
- [ ] Timing is available by Section, Module, and question without changing grading.
- [ ] Question Category breakdowns appear only when the Answer CSV supplied category data.
- [ ] Filters cover incorrect, unanswered, marked, Section, and Module states.
- [ ] Question review shows the PDF content, learner response, accepted answer, correctness, timing, and review state without explanations.
- [ ] Retake creates a new Attempt and leaves the original Results unchanged.
- [ ] Practice Mistakes opens the Practice Builder using missed questions from exactly one completed Attempt and its Test Package.
- [ ] Results remain tied to the immutable Test Package revision used by the Attempt.
- [ ] Tests prove MCQ and SPR grading, unanswered denominator behavior, timing aggregation, filtering, Retake immutability, and Practice Mistakes prefill through public interfaces.
